# Logic Quick Router updates

This repository only holds the files that installed copies of Logic Quick Router use to update themselves: `appcast.xml` and a signed update zip, attached to each release. It contains no source code.

Updates are signed: the app only installs an update whose EdDSA signature matches the key built into it.

To install Logic Quick Router for the first time, use the download you received when you bought it, and follow the install guide included in it.
